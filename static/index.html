Chào mừng đến với GitScrum AI!

Công cụ hỗ trợ Scrum Master và Tech Lead tự động hóa báo cáo Daily Standup, theo dõi vận tốc Sprint và giải phóng điểm nghẽn Pull Request.

1

Nhập Repository

Nhập tên repo GitHub (vd: company/repo) và tìm Milestones.

2

Chọn Milestone

Mỗi GitHub Milestone tương ứng với 1 Sprint đang chạy hoặc đã đóng.

3

Báo Cáo Tức Thì

Tự động xuất Standup 3 cột, phát hiện PR quá hạn và gửi Slack Webhook 1 chạm.

🔑 Cấu Hình GitHub Personal Access Token

GitHub hạn chế 60 yêu cầu/giờ với tài khoản ẩn danh. Nhập Token cá nhân (Classic PAT hoặc Fine-Grained) để nâng giới hạn lên 5,000 yêu cầu/giờ và quét được cả Private Repositories.

🔒 Token chỉ được lưu trong localStorage trên trình duyệt của bạn, hoàn toàn bảo mật và không lưu trên server.
